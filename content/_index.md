# Welcome

This is a sample [Hugo](https://gohugo.io) site, scaffolded to be:

- Committed from a local repo to GitHub
- Built and deployed automatically with **GitHub Actions**
- Published live on **GitHub Pages**

It ships with a few sample pages, a small blog section, and a live
**API reference** page (see the menu) rendered from a bundled OpenAPI spec.

Nothing needs to be installed locally — GitHub Actions installs Hugo
and builds the site for you on every push.
