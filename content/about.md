# About this site

This site is a starter scaffold. Replace this page, the sample posts,
and the OpenAPI spec under `static/openapi/openapi.yaml` with your
own content.

Structure:

```
content/          # Markdown pages & posts
layouts/          # Minimal custom HTML templates (no external theme)
static/           # CSS and the sample OpenAPI spec
.github/workflows # The GitHub Actions build + deploy pipeline
```
