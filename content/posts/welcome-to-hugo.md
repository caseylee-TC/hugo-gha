Hugo builds this whole site from plain Markdown files like this one in
a fraction of a second, with no runtime dependencies once it's built —
the output in `public/` is static HTML, CSS, and JS that GitHub Pages
can serve directly.

Add new posts by creating another `.md` file under `content/posts/`.
